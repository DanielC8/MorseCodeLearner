What is Morse Code?

Morse Code is a way to send messages using just two signals:

●

Dot (short signal)

Written as a period: .

▬

Dash (long signal)

Written as a hyphen: -

People used Morse Code to send messages over telegraphs and radios. The most famous Morse Code signal is SOS (... --- ...), which means "Help!"
